Ember Run 3D: Volcano Ridge — a real 3D flight game: chase view behind a low-poly rescue jet over a 3D volcano archipelago at dusk. The world is rendered in 3D with our own projection code on Canvas 2D (no engine, no network): a low-poly terrain mesh with a smoking volcano, lava streams and a glowing crater, a sea with islands, drifting embers and a setting sun. Fly through 10 golden rings, pick up 4 survivors at the glowing orange beacons, grab fuel canisters on the way, chain objectives into a combo up to x5 — then land on the Meridian strip to see the full debrief. An autopilot flight lands with a score of 23,811 (8/10 rings, 4/4 rescues, no damage).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with arrow keys (Up = climb, Down = descend, Left/Right = bank), W/S for throttle, P to pause, M to mute. Press Enter to start.
